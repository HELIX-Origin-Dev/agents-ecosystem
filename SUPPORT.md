# Support

## Where to ask

| Need | Use |
|---|---|
| Reproducible defect | Bug report issue form |
| Proposed behavior or new adapter | Feature request issue form |
| Usage question | Discussions or a clearly titled issue after checking the docs |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md); do not open a public issue |

## Before opening an issue

Read:

- [Installation](docs/user/installation.md)
- [Scope and collision policy](docs/user/scope-and-collision-policy.md)
- [Troubleshooting](docs/user/troubleshooting.md)
- [Agent native ecosystem layouts](docs/developer/research/agent-native-ecosystem-layouts.md)

## Information to include

For the fastest help, include:

- the exact command you ran with `--dry-run`;
- selected agent IDs and scopes;
- product and platform names without machine-specific absolute paths;
- expected versus actual behavior;
- relevant dry-run output with all sensitive details removed;
- whether the destination already existed.

Never include secret values, webhook URLs, cookie exports, environment values, usernames, passwords, or tokens.

## Response expectations

Issues are reviewed by maintainers and triaged as documentation, installer, adapter, or native-layout questions. Bug reports with a dry-run plan and a clear reproduction are prioritized.
